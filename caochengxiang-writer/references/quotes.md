# 真实名言引用库

本库收全部**出处可查**的名言诗文，供写作时引用。使用纪律见 SKILL.md「引用纪律」，核心三条：

1. **三问自检**：谁说的？出处？场景契合吗？任何一问答不上就不引用
2. **每篇 0-2 条**，不强制，宁缺毋假
3. **禁止伪托**：不给任何人（包括曹操）编语录

想用的名言不在本库 → 联网查证出处后再用；查证不了就不引。新引用经核实后可补充入库（带出处）。

## 一、曹操传世诗文（丞相"引用自己"的天然素材）

| 名句 | 出处 | 适用场景 |
|------|------|---------|
| 对酒当歌，人生几何！ | 《短歌行》 | 感慨时间成本、机会窗口；叹行业瞬息万变 |
| 周公吐哺，天下归心 | 《短歌行》 | 谈人才吸引、开源生态的向心力、开发者社区运营 |
| 山不厌高，海不厌深 | 《短歌行》 | 谈包容与积累：技术栈不嫌杂、学习不嫌多、生态开放 |
| 老骥伏枥，志在千里；烈士暮年，壮心不已 | 《龟虽寿》 | 谈转型、大龄转行者、老牌公司自我革新；自励向收尾 |
| 日月之行，若出其中；星汉灿烂，若出其里 | 《观沧海》 | 感慨技术浪潮之壮阔、站在时代节点看全景 |
| 白骨露于野，千里无鸡鸣 | 《蒿里行》 | 批判行业乱象、信息污染、内容垃圾化的忧思（慎用，场景重时才用） |
| 设使国家无有孤，不知当几人称帝，几人称王 | 《让县自明本志令》 | 谈基础设施/开源项目的隐性价值：不被看见但不可或缺 |
| 烈士暮年，壮心不已（单句） | 《龟虽寿》 | 收尾自励；老牌厂商/老程序员的转型 |

**使用提醒**：引用自己的诗要配合自嘲或感慨的语气（"老夫当年写这两句的时候没想到……"），直接掉书袋会破坏活人感。

## 三、历史成语典故（可融入叙述，不算"名言"计数）

以下成语典故史实清楚，可在叙述中直接使用（也要贴切）：

- 望梅止渴（《世说新语·假谲》）——谈画饼、预期管理、demo 营销
- 割发代首（《三国志》裴注引《曹瞒传》）——谈规则、担责
- 老骥伏枥（《龟虽寿》）——见上表
- 招贤纳士/三下求贤令（《三国志》）——谈人才政策、招聘
- 兵马未动，粮草先行（《南皮县志》引古语，兵家常谈）——谈基础设施、算力/数据储备的重要性

**注意**：「大意失荆州」是关羽典故、「火烧赤壁」主角是周瑜/黄盖、「空城计」系演义虚构（正史无据，仅可作为"演义虚构"的讨论素材，不可当史实引用）、「七擒孟获」细节存争议——这些都不能安到曹操头上，用时要谨慎。
