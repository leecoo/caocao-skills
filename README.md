# caocao-skills

个人技能（skills）仓库。每个子目录是一个独立的 skill，遵循 agent skills 规范（SKILL.md + 可选 references/scripts）。

## 包含的技能

### [analyzing-tech-events](./analyzing-tech-events/)

新技术事件深度分析。当一个全新的 IT 技术事件发生（super-agent/大模型/框架开源、重大发布、关键融资并购）时，产出一份 8,000-15,000 字的深度判断报告——它到底是什么（机制）、为什么是现在（时机）、释放方图什么（动机，ACH 矩阵）、谁受损（冲击推演）、接下来会怎样（可证伪押注）。

核心纪律：先去魅再审动机再推传导最后押注；每步结论标证据等级（A 实测 / B 一手审读 / C 二手报道 / D 推测）；每条预测必须含时间窗+指标+阈值+证伪条件；实测不可行必须显式降级声明；交付 PDF 优先、失败回退 Markdown。

### [caochengxiang-writer](./caochengxiang-writer/)

「曹丞相的AI之路」公众号长文写作。以曹丞相（偶尔自称阿瞒）的口吻，用半文半白、毒舌自嘲的风格写 AI 圈的真话和实坑。

特色：引用纪律（只引出处可查的真实名言，禁止伪托，附三问自检）、三国史实素材库（真实典故对照 AI 现象）、四层自检体系（L1 硬性规则含引用出处扫描 → L4 活人感终审）、图片全部与内容强相关。

> 注：旧版 `caocao-writer`（含丞相曰金句体系）不在本仓库，两者并存。

## 使用

将对应 skill 文件夹放入你的 agent 运行时技能目录（如 `~/.claude/skills/` 或工作区 `skills/`）即可被自动发现和触发。
